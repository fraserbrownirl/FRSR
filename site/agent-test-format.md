## Scoring checklist

| Check | Look for |
|--------|-----------|
| Problems | 2–3 lines, `[known]` / `[inferred]`, correction invite |
| Coverage | Matches draw on more than one obvious project name |
| Blocks | **Lesson** first; insight / did / inference / reasoning as short bullets |
| Combined read | ≤4 lines |
| Experiment | hypothesis, do, success, fail |
| Fraser | one forwardable question |

Weak output tends to be long unheaded prose, unnamed projects, or claims with no documented status on the page.
