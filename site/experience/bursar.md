# Bursar

## Structural problem

Crypto payments expose users to gas, addresses, signing screens and chain selection.

## Insight

A conversational agent can hide settlement mechanics while preserving explicit authorisation and verifiable checks.

## What Fraser did

Built a 9B payment agent at NEAR Hackathon using NEAR Intents, skills, in-weights checks, pinned firmware and Apple Secure Enclave signing. The profile reports mainnet USDC, x402, MPP and an iOS QR/Face ID flow.

## Status

Working implementation reported; 19 attack demonstrations reported (3 stopped in the model and 16 by external code guards). No adoption or revenue figures supplied.
