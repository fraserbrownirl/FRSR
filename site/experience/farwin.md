# FarWin

## Structural problem

Lottery type games constantly fail to be completely decentralised.

## Insight

Leveraging smart contracts, bonding curves and NFT technology, we were able to solve this problem once and for all.

## What Fraser did

FarWin is the first time that such a game of chance is completely unstoppable.

## Status

Selected for a fully funded one-month Funding the Commons residency in Buenos Aires, October 2025 (20 selected from over 1,000 applicants). Project live as an MVP but in flux following Farcaster changes and gambling regs considerations.
