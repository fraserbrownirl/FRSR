# reintro.ai

## Structural problem

A plain script or long text does not become an illustrated audiobook without heavy manual production.

## Insight

A script can enter a pipeline that segments text, classifies each sentence (dialog, narration, picture-only), harvests what can be photographed, and cuts visuals to a spoken bed where narration is the soundtrack and description is never spoken.

## What Fraser did

Built reintro — rules, gates, scripts, and agent skills that run the pipeline

## Status

Live site and open repo; illustrated-audiobook pipeline with pytest gates and ffmpeg assembly.
