# many.guru

## Structural problem

Simply asking an LM for advice creates fairly generic results by steering the agent to first identify which authorities or gurus might offer the best advice. Users can get better results.

## Insight

Matching a question to a relevant guru can improve the starting point for an AI conversation.

## What Fraser did

Created an advice app described as matching an issue to a guru, offering initial advice and linking to Claude, Grok or ChatGPT.

## Status

The web app is live and under development.
